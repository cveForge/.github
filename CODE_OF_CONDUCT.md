# Contributor Covenant Code of Conduct

## Our Pledge
We pledge to make participation in cveForge a harassment-free experience for everyone,
regardless of background, skill level, or experience.

## Our Standards
**Acceptable:**
- Professional, constructive technical discussion
- Helping others learn defensive and offensive security concepts
- Responsible disclosure practices

**Not acceptable:**
- Using PoC code against unauthorized targets
- Sharing credentials, PII, or private data obtained through PoCs
- Harassment, threats, or abusive language

## Enforcement
Violations may result in removal from the organization.
Report issues by opening a GitHub Issue.
