# Security Policy — cveForge

## About This Repository
This organization hosts educational PoC implementations of publicly disclosed CVEs.
Every CVE documented here has already been publicly assigned and published.

## Responsible Use
- Use only on systems you **own** or have **explicit written permission** to test
- Unauthorized use against third-party systems is illegal in most jurisdictions
- cveForge assumes no liability for misuse

## Reporting an Issue with Our PoC Code
If you discover a bug, inaccuracy, or unintended behavior in our PoC:
- Open a GitHub Issue with the `security` label
- Describe the problem clearly; no need for private disclosure for PoC code quality issues

## Reporting a NEW CVE
If you have discovered an unreported vulnerability and want to collaborate on a PoC:
- Ensure the vulnerability is **already publicly disclosed** (CVE assigned, vendor notified)
- Open an Issue describing the CVE ID and linking the advisory
- Do NOT submit exploits for unpatched / zero-day vulnerabilities

## Legal Notice
All PoC code is provided **for educational and authorized security research only**.
