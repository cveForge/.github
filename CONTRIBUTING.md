# Contributing to cveForge

## Purpose
This repository contains proof-of-concept (PoC) code for publicly disclosed CVEs.
Contributions must improve accuracy, documentation, or detection guidance.

## How to Contribute
1. Fork the target repository
2. Create a branch: `git checkout -b improve/CVE-XXXX-XXXXX`
3. Make your changes with clear commit messages
4. Open a Pull Request describing what changed and why

## Acceptable Contributions
- Accuracy fixes (wrong version range, wrong CWE, wrong CVSS)
- Improved PoC reliability or additional test cases
- Better documentation or usage examples
- Mitigation / detection improvements

## Not Accepted
- PoCs targeting systems without explicit authorization scope
- Code that escalates impact beyond the original CVE
- Obfuscated or encrypted payloads
